# jinjiang-skill

一个中文小说文风 skill，给 Claude Code / Claude Agent SDK 用。

解决的问题不是词汇量，是 AI 写中文小说时的**默认人格**：一个礼貌的、要把每件事解释清楚的、每段都想升华一下的叙述者。
本 skill 用两套实测出来的文风替换掉那个默认人格，并给出可以 grep 出来的验收标准。

## 两个语音包，按时代自动路由

| 故事时代背景 | 用哪个包 |
|---|---|
| 上古 ~ 清中叶（1840 年前），含架空古代、仙侠、武侠、朝堂、神话 | **古典江湖体** `classical` |
| 晚清、民国、近现代、当代、都市 | **当代白描体** `modern` |
| 近未来、远未来、赛博、末世、星际、无限流、游戏系统流 | **当代白描体** `modern` |

一句话版：**没有电的世界用古典包，有电的世界用当代包。**

判定由 AI 自己完成，不问用户，动笔前把判定结果亮一行出来让人能一句话推翻。
边界情况（末世废土、晚清、蒸汽朋克、星际修真、穿越双线）在 `SKILL.md` 里已经逐条裁决好。

## 为什么是两个包，不是一个

两种文风在几乎每个可测维度上是相反的。以下为两份源语料的全文实测，每万汉字归一化：

| 指标 | 古典江湖体 | 当代白描体 |
|---|---|---|
| 平均句长（汉字/句） | 42.6 | 26.5 |
| 每句逗号数 | 3.25 | 1.54 |
| 对话归属后置占比 | 10% | 70% |
| `道：` | 50.5 | 1.0 |
| `说：` | 0.2 | 13.9 |
| `便` | 34.8 | 3.7 |
| `似的` | 8.4 | 1.3 |
| `倘若` | 2.8 | 0.02 |
| `感到` | 0.02 | 1.4 |

把两套合并 = 取平均值 = 正是"AI 味"的定义。所以做成两个互斥的包，外加一层共享的去 AI 腔内核。

## 安装

```bash
git clone https://github.com/patthx/jinjiang-skill.git
cp -r jinjiang-skill/zh-novel-voice ~/.claude/skills/
```

之后说"写一段晚唐背景的江湖片段"或"这段有 AI 味，帮我洗一下"即可触发。

## 自检脚本

```bash
python zh-novel-voice/scripts/check.py 草稿.txt --style classical
python zh-novel-voice/scripts/check.py 草稿.txt --style modern
```

报出句长、每句逗号数、归属方式、风格词上下限、AI 腔短语命中，逐项 OK / FAIL。

交叉验证结果 —— 检查器能干净地区分两种文风：

| | `classical` | `modern` |
|---|---|---|
| 古典风格样本 | **通过** | 16 项不合格 |
| 当代风格样本 | 9 项不合格 | **通过** |

## 方法论说明

黑名单不是凭感觉列的，是对着语料数出来的。

这一点有实际影响：`缓缓`、`轻轻`、`微微` 通常被当成典型 AI 腔词，但实测发现古典侧用得比当代侧凶五倍（2.8/3.9/3.1 对 0.6/0.5/0.9）。同样被误判的还有 `不动声色地`、`意味深长`、`沉声道`。反过来古典侧真正的硬禁忌是 `感到` —— 59 万字里只出现 12 次。

所以短语黑名单按命中率分了两级：**两份语料中 0 次命中的 27 条**判 FAIL，**用过但极罕见的 15 条**只报 WARN。

## 关于内容

本仓库收录的是抽象出来的写作技法规则、统计指标和自检工具。

- 所有示例段落均为演示语法结构而自撰，不含任何作品的文本片段。
- 统计基线来自私有语料，语料本身不随本仓库分发。
- 语音包以文体特征命名（古典江湖体 / 当代白描体），不指向任何特定作者或作品。
