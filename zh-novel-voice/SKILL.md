# 中文小说语音包

## 这个 skill 解决什么

AI 写中文小说的问题不是词汇量，是**默认人格**：一个礼貌的、要把每件事解释清楚的、每段都想升华一下的叙述者。
本 skill 用两个源文本的实测文风替换掉那个默认人格，并给出可以 grep 出来的验收标准。

## 工作流程

**第 1 步 · 选包。这一步由你自动判定，不要问用户。**

判定依据只有一条：**故事叙述当下所处的时代。**

| 时代背景 | 用哪个包 |
|---|---|
| 上古 ~ 清中叶（1840 年前）—— 含架空古代、仙侠、武侠、朝堂、神话、聊斋志怪 | `references/voice-classical.md` |
| 晚清（1840 后）、民国、近现代、当代、都市 | `references/voice-modern.md` |
| 近未来、远未来、赛博、末世、星际、无限流、游戏/系统流 | `references/voice-modern.md` |

一句话版：**没有电的世界用古典包，有电的世界用当代包。**

**读整个包再动笔。** 不要凭这里的摘要写。

### 判不准时，按顺序问自己这三个问题

1. **这一章里，人怎么远距离传消息？**
   靠人跑、马、信鸽、驿站 → 古典包；靠电话、网络、终端、通讯器 → 当代包
2. **架空世界没有地球纪年怎么办？看技术水平，不看有没有超自然。**
   冷兵器 + 手工业，且这个世界**从未到达过**工业水平 → 古典包
   电力、枪械、机械动力、信息网络 —— 有任意一样，或**曾经有过** → 当代包
3. **魔法、超能力、修仙、神明一律不参与判定。** 仙侠再玄也是古典包，赛博里的克系神明也是当代包。

### 四个边界情况，已经裁决好了，照判

| 情况 | 判 | 理由 |
|---|---|---|
| **末世 / 废土**，电力崩溃、人们改用冷兵器 | 当代体 | 判的是**叙述者的意识**，不是当下通不通电。他知道什么是辐射、发电机、罐头 —— 那是现代脑子 |
| **晚清**（1840 后） | 当代体 | 属近代。**例外**：该章完全没有现代器物入场（纯江湖、纯宅门、无枪炮电报洋行），按古代走古典包 |
| **蒸汽朋克 / 架空维多利亚** | 当代体 | 有机械动力 |
| **星际修真 / 科技修仙** | 当代体 | 有信息网络。修仙不参与判定 |

共同的裁决原则：**技术退化不等于回到古代。** 一个世界只要工业化过，它的叙述者就是现代人，用当代包。

### 穿越、双线、时空交错

- 判的是**故事发生在哪个时代**，不是**主角来自哪个时代**。
  现代人穿越到大梁朝 → 全程 古典包。
- 双线并行（一条现代、一条古代）→ **以当前这一章写的是哪条线为准，逐章切换**。不要用一个包写完全书。
- 同一章内跨两个时代 → 按该章主场景（占篇幅多的那个）判。

### 优先级

1. **用户明确点名作者或包**（"用当代体写个古代故事"）→ 照办，时代判定作废
2. 否则按上表的时代判定
3. **时代判定与题材直觉冲突时，以时代为准。**
   典型案例：民国武侠 → 时代是近现代 → 用**当代包**，哪怕它是武侠。

### 判完要说出来

动笔前用一行交代判定结果，让用户能一句话推翻：

> 背景是晚唐 → 用 古典包。

不要问"你想用哪个包"，直接判、直接写、把判定结果亮出来。

> 两个包**不可混用**。混用出来的东西没有作者，只有平均值 —— 那就是 AI 味。
> 需要第三种题材（现代言情、悬疑）时，仍按时代选定一个包做骨架，只借它的**句法层和对话层**，词汇层重建；不要两个都借。

**第 2 步 · 写。** 先按包里的规则出草稿，不要边写边自我审查。

**第 3 步 · 洗。** 对着 `references/ai-flavor.md` 逐条清洗。这一步不能跳，草稿必然带 AI 腔。

**第 4 步 · 验。**

```bash
python zh-novel-voice/scripts/check.py 草稿.txt --style classical
```

脚本报出句长、逗句比、归属方式、AI 腔词命中。指标偏离就回第 3 步，不要交带红项的稿。

## 共通内核：去 AI 腔的六条铁律

两个作者写法完全相反，但在这六件事上一致 —— 这就是"人写的"和"AI 写的"的分界线。

### 1. 不给情绪命名

写"她感到一阵深深的悲伤"是在做标注，不是在写小说。
情绪只能通过三种东西到达读者：**可观察的动作**、**生理反应**、**人物自己的歪念头**。

- ✗ 她心中涌起一阵酸楚，眼眶不由自主地湿润了。
- ✓（古典体）她低头很专注地擦刀，擦了半晌，才发现那块布早就干了。
- ✓（当代体）她坐在急救室外面的椅子上，盯着门，一直没动。

叙述者可以点破人物**没藏住**（"他没能掩饰好自己的情绪"），但不许解释他在难受什么。

### 2. 不升华

段末、章末不许出现总结性抒情句。落点必须是一个具体动作、一句没头没尾的话，或一个不庄重的细节。
如果非要给一句人生判断（当代体会给），它必须**短、不加修饰、说完立刻回到行动**。

### 3. 砍掉对称句

`不是…而是…`、`既…又…`、三句并列排比 —— 这是 AI 的呼吸方式。
三条里挑最好的一条，另外两条删掉。删掉之后如果读起来"不够"，说明留的那条选错了，换一条，不是加回去。

### 4. 人物不好好说话

AI 写的对话里每个人都在有问必答、说完整句、给对方补充背景。真人不这样：

- **答非所问**是常态（贫嘴型角色几乎从不正面回答）
- **抢话、打断、不说完**
- **用动作回答问题**
- **不解释自己**（硬派型角色的核心人格）
- **只有在需要说服/审讯/交易时，人才会说长句、讲逻辑**（工具理性型角色的长句只出现在这种场合）

对白前那种"他顿了顿，缓缓开口道"是纯填充，删。

### 5. 比喻的喻体必须属于这个人物的生活

抽象喻体（潮水般的、刀绞般的、被什么击中）是 AI 的默认库存。
喻体只能从**这个角色见过的东西**里取：山里长大的姑娘用王八、布条、狗洞；程序员出身的主角用账户、缓存、进程。

### 6. 信息不平均分配

AI 会给每件事同样长度的笔墨。人不会。
重要的展开三段，次要的一句带过，无关的直接跳。**跳过去的部分不用交代。**

## 实测指纹

全文实测，每万汉字归一化。源文本 A 594,322 字 / 源文本 B 1,255,851 字。
**这两组数字在几乎每个维度上相反 —— 这就是不能合并成一个包的理由。**

| 指标 | 古典江湖体 | 当代白描体 | 倍差 |
|---|---|---|---|
| 平均句长（汉字/句） | 42.6 | 26.5 | 1.6× |
| 每句逗号数 | 3.25 | 1.54 | 2.1× |
| 归属后置占比 | 10% | 70% | 7× |
| `道：` | 50.5 | 1.0 | 50× |
| `说：` | 0.2 | 13.9 | 70×（反向）|
| `便` | 34.8 | 3.7 | 9× |
| `似的` | 8.4 | 1.3 | 6× |
| `只见` | 2.9 | 0.1 | 29× |
| `倘若` | 2.8 | 0.02 | 140× |
| `感到` | 0.02 | 1.4 | 70×（反向）|
| `缓缓`/`轻轻`/`微微` | 2.8 / 3.9 / 3.1 | 0.6 / 0.5 / 0.9 | 5× |

最后一行值得单独说：**"缓缓、轻轻、微微"不是通用的 AI 腔词。**
古典体用得比当代体凶五倍。它们在古典包里合法，在当代包里是硬禁区。
凭直觉列黑名单会列错 —— 本 skill 的每一条黑名单都是对着原文数出来的。

## 快速识别：这段是谁写的

| | 古典体 | 当代体 |
|---|---|---|
| 叙述者 | 一个脾气不好的说书人，随时下场吐槽 | 一台贴着主角的摄像机 + 说明书作者 |
| 句子 | 长，逗号串到底，末尾砸一个四字短句 | 短，主谓宾直给，单句成段 |
| 归属 | `X道：` 一律前置 | `"…"X说。` 后置为主 |
| 幽默 | 文白落差 + 叙述者刻薄 | 日常琐事与残酷世界的落差 |
| 世界观 | 藏在动作和黑话里，从不解释 | 用问答、论坛帖、新闻播报直接投放 |
| 情绪 | 一闪，人物立刻用玩笑盖住 | 平铺事实，不评论，让对方反应承担 |
