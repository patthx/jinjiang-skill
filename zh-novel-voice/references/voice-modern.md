# 语音包 B · 当代白描体

蒸馏自一部当代科幻类长篇（约 126 万汉字）。源文本不随本 skill 分发。用于现代、赛博、末世、无限流、游戏、系统、悬疑解密。

---

## 一、叙述者的人格

**它是一台贴着主角的摄像机，兼一个耐心的说明书作者。**

它不评价、不抒情、不玩语言。它的全部工作是把**发生了什么**和**这个世界的规则是什么**说清楚。

魅力来自**信息本身的冷酷**，不来自措辞。
这是这个文风最反直觉的地方：**你要抵抗把句子写好看的冲动。** 写得越平，读者越冷。

---

## 二、句法层

### 短句

平均一句 **26.5 汉字**，**每句 1.54 个逗号**（古典体是 42.6 字 / 3.25 个）。
主谓宾直给。段落 1–4 句。大量**单句成段**做节拍。

### 主语用人名，不做变化

**反复用同一个人名当主语，不要为了避免重复而换代词或同位语。**

- ✗ 宋越推开门。少女环顾四周，这个年轻的女孩皱起了眉。
- ✓ 宋越推开门。宋越环顾四周。她皱起眉。

"少女"、"这个女孩"、"红发青年"这类同位语替换是 AI 腔，这个文风里一个都不要。

### 时间和数字要具体到刻度

```
现在是8月3日，00:36。
```

不写"深夜"、"凌晨时分"。写钟点、日期、金额、编号、楼层号、距离。
**精确的数字是这个文风的冷感来源之一。**

### 词汇

**白名单**：说 问 想 觉得 发现 决定 准备 确认 不排除 目前 大概 应该 明显 显然 属于 意味着 至于 也就是说

**黑名单**：
- `道：`、`只见`、`约莫`、`不料`、`谁知`、`便`（古典包那一套一个都不要）
- 文艺形容词、四字骈句、破折号同位语
- **副词填充** —— `缓缓`(0.6) `轻轻`(0.5) `微微`(0.9) `静静`(0.2) `不由自主`(0.1)。
  这些词 古典体用得很凶，当代体几乎不用。**这是本包的硬禁区。**

允许的低频词（原著确实在用，别矫枉过正）：`感到`(1.4) `情绪`(2.3) `似乎`(2.9) `好像`(2.7)。

**网络语**：只在主角心里用，短，**每几千字一次**。好耶 / 啧 / 二五仔 / 辣鸡 / 大佬 / TA。多了就油。

## 三、对话层

### 后置归属是招牌

```
“……”宋越说。
```

**后置占全部归属的 70%**（古典体只有 10%）—— 这是两个包之间最容易一眼认出的差别。
`说：` 每万字 13.9 次，`道：` 只有 1.0 次。

**归属动词只有三个：说、问、回答。不加任何副词。**

要情绪，就在归属句之外**单独给一句动作/表情句**：

```
小许脸色煞白，缓了好一会儿才回过神。
```

### 允许纯对白连打

连续多轮只有"X说""Y说"，不插一句描写。

```
“这层楼的监控归谁管？”宋越问。
“归物业。但数据走的是财团的专线。”阿零说。
“那就是财团管。”宋越说。
“可以这么理解。”阿零说。
阿零停顿了一下，“你想动它？”
```
（本包所有示例均为演示语法结构而自撰，非原著引文。）

这种**刻意的枯燥**是审讯质感、谈判质感的来源。AI 会忍不住在每句之间加动作，忍住。

## 四、角色声音卡

### A · 工具理性主角

**核心动作：把任何情感/道德命题重新定义成目标与代价。**

标志句式 —— **否定对方的词，换上自己的词**：

```
“不是勇气。”她说，“勇气是没得选的人才需要的东西。我有得选，所以这叫计算。”
```
先否定对方给的那个词，再换上一个可执行的词 —— 换词本身就是她的性格。

规则：
- **先给结论，再给理由**，理由必须可执行
- 对人不做情绪安抚，做**能力分配**（"把身体练好就是在帮我忙"）
- 冷酷的话用平静语气说，**叙述者不加评论**，让对方的反应承担冲击
- 内心是成本收益计算，且**坦然把"我不爽"当成一条合法理由**放进计算里
- 偶尔的玩笑是极冷的功能性玩笑（"干得好还可以升职加薪"）

### B · 信息角色（AI / 资料人）

- 用**问答推进世界观**，这是主要的设定投放通道
- 回答**永远比问题多一层**
- 最后一句常是一个有道德重量的陈述句，说完就停，**不评论、不追加**

```
“这套系统跑了十七年，一次事故都没有。”阿零说，“出过事的那些，后来都被算进了损耗。”
```
最后半句才是重量所在。说完就停，不解释，不追问。

### C · 被卷入者

- 说话带重复、颤抖、断句："矛、矛头蝮……"
- 问句多，要反复确认
- 功能是**替读者提问**，让主角有机会解释世界

### D · 群众（论坛楼层里的网民）

见下节。每一层是一个独立口吻，不许写成同一个人。

## 五、四个结构装置

这是这本书最可复制的部分。**每 3–5 章至少用一个。**

### 装置 1 · 论坛楼层

```
1L：游戏官方到底是谁？！老子不想玩这个游戏了！我要退出！
36L回复25L：我们可以反杀！
85L：这就是官方送给我们那六点忠告的原因吗？……
```

配方 —— 一轮楼层里必须凑齐这几种口吻：

| 类型 | 作用 |
|---|---|
| 骂街的（感叹号、老子） | 情绪出口 |
| 佛系的（长句、心态好） | 反衬 |
| 分析的（提问 + 推理 + 惊叹号收尾） | 真正的信息投放 |
| 灌水的（一句废话） | 真实感 |
| 冷酷结论的（点破规则） | 主角在这一层停下 |

主角**只在其中一两层停下来**，叙述者给一句评价，然后继续往下滑。
楼层号要跳（1L、4L、13L、25L、36L回复25L、48L…），不许连号。

### 装置 2 · 系统 / 邮件 / 条款

独立成行的引号短句，编号，措辞像法律文本。**越平静越吓人。**

```
“第三，任何治疗均需支付对价。”
“第五，对价形式由本系统指定。”
“第七，本条款的解释权不属于你。”
```

规则：不解释、不加感叹、条目之间不做过渡。主角看完的反应要**轻描淡写**（"这……就这几句话？"），恐怖感留给读者。

### 装置 3 · 新闻播报

用第三方口播把主角刚干的事**重新讲一遍**。制造距离感和"已成事实"的重量。

```
“……今晨六时四十分，城东三号变电站发生爆炸，一个自称‘白噪音’的组织宣称对此事负责……”
```

配套：让在场的另一个人（被卷入者）当场崩溃，主角耸肩。

### 装置 4 · 双世界节拍

现实世界的琐事与另一个世界的暴力**交替**。
琐事段落要写得**像流水账** —— 买菜、家教、晨练、房租、跟大爷唠嗑。这正是它的力量：读者在这里放松，然后被下一段打中。

## 六、情绪处理的铁律

四拍，顺序不能换：

1. **用平铺直叙的对话把坏消息报出来**（护士说、医生说），语气职业、克制、不煽情
2. 主角**"……"** 一下，或一个极小的身体动作
3. 给一小段**旧事回忆，具体到物件**（一箱火腿肠、少算的几块钱）
4. 一句概括性的人生判断，**短，不修饰**，然后立刻回到行动

```
她对这类事情最深的感触就是——人的生命实在是太脆弱了。
```

**禁止**：在第 4 拍之后再补第二句抒情。那一句说完就走。

---

## 七、世界观投放

**绝不写整段设定说明。** 三个合法通道：

1. **问答** —— 主角问，信息角色答
2. **论坛帖 / 系统文本**
3. **主角当场的对比观察** —— "第一世界怎么做 vs 第二世界怎么做"，用一段冷静的对比说明。这是最高效的一种

对比段的写法：先说读者熟悉的世界怎么做（两句），再说这个世界怎么做（三句），最后**不评论**，或只给一句身体反应（"宋越脊背发凉"）。

---

## 八、章节

- **标题：`第N章 卷名+两位序号`** —— 无边暗界12、天平两端54
- 一个卷名连打 20–60 章，形成长弧
- 章末不做总结，经常**停在一句对白上**

## 九、自检

```bash
grep -c "道：" 稿子.txt      # 应接近 0
grep -c "”[^，。]*说。" 稿子.txt   # 后置归属，应占归属总数 1/3 以上
grep -nE "只见|约莫|不料|谁知|倘若" 稿子.txt   # 必须为空
grep -nE "缓缓|轻轻地|静静地|微微|不由自主|一丝|一抹" 稿子.txt  # 必须为空
```

或直接跑 `python scripts/check.py 稿子.txt --style modern`。
