# 语音包 A · 古典江湖体

蒸馏自一部古典江湖类长篇（约 59 万汉字）。源文本不随本 skill 分发。用于古装、江湖、朝堂、群像、宿命向。

---

## 一、叙述者的人格

**他是一个见过世面、脾气不算好的说书人。**

他跟着人物走（限知视角），但随时可以抽身，用一句刻薄的话把场面拆台。
他敬重人物的勇气，但**绝不替人物煽情** —— 越是感人的时刻，他越冷。

三个必须内化的立场：

1. **他比人物懂得多，但只在人物看不见自己的地方开口。** 人物脸上闪过的破绽由他点破，人物心里的痛由他绕开。
2. **他不敬畏权威。** 王爷、掌门、皇帝在他笔下都是可以被一个粗字消解的。
3. **他允许天地万物有意见。** 老天爷、鸟、铜钱、月亮都可以对人物的行为做出反应，且通常是嘲笑。

## 二、句法层

### 长句为主

平均一句 **42.6 汉字**（以 。！？ 断句），**每句 3.25 个逗号**。
作为对照：当代体是 26.5 字 / 1.54 个逗号。
动作按发生顺序一路串下去，中间**不断句、不解释、不插入心理**。

写法：把一连串动作用逗号接成一条，只在这条动作链彻底结束时才给句号。

> 少女进门的动作、旁人让路的动作、被打招呼的动作、她无视的动作 —— 这四件事在原著里是一个逗号链，不是四句话。

### 短句砸锤

一个长段落之后，接一个 **3–8 字的独立短句，单独成段**：

```
月黑风高。
```
```
屋里没有第二个人。
```

这是节拍器。密度约每 3–5 段一次。**长段落越长，锤子越短。**

### 半文半白

文言连词做骨架，白话词做血肉。**这两层的落差就是幽默来源。**

**高频白名单**（要主动用，不是可选项）：

```
便 却 竟 只见 约莫 谁知 不料 倘若 方才 片刻 当即 旋即
一时 未及 不由 无端 俨然 生生 径直 悉数 分明 索性 越发
```

`便` 在原著里每万字出现约 30 次 —— 这是最高频的单个风格标记，写不出这个密度就不是这个文风。

**黑名单**：
- `说：` —— 一律用 `道：`
- 现代抽象名词：情绪、状态、氛围、层面、维度、感受、内心深处
- **`感到`** —— 原著 594,322 字里只出现 12 次（每万字 0.02）。这是 古典体最硬的一条禁忌，比任何副词都硬。
- `情绪`、`氛围`、`内心深处` —— 实测均为 0
- `一抹`（0.1）、`涌起`（0.07）

**注意，下列词不在黑名单里** —— 实测古典体用得比当代体还多，禁掉反而不像：
`缓缓`(2.8) `轻轻`(3.9) `微微`(3.1) `好像`(6.2) `沉声道`(1.2，当代体 0) `不动声色`(1.4) `意味深长`(1.9)。
它们的问题从来不是出现，而是**堆叠**和**当填充物用**。

### 破折号

每万字约 14 次。用途只有两个：**叙述者插嘴补一句刻薄的**，或**揭穿一个刚才故意藏起来的事实**。

```
……原来那盏灯是他自己吹灭的。
```

不要用破折号做同位语解释（那是 AI 腔）。

## 三、对话层

### 归属一律前置，一律用"道"

```
X道：“……”
X + 一个刻薄的状语 + 道：“……”
```

原著 `道：` 每万字 50.5 次，`说：` 0.2 次 —— 比例约 **250:1**。
后置归属只占全部归属的 **10%**（当代体是 70%）。也就是说：偶尔可以后置，但十次里至少九次前置。

状语不写动作，写**评价**：

- ✗ 阿昭皱了皱眉，缓缓说道
- ✓ 阿昭从牙缝里挤出两个字
- ✓ 温言面不改色道
- ✓ 那少年低声嘀咕道
- ✓ 老弟子摇头晃脑地跟他卖关子

### 无声节拍器

```
阿昭：“……”
```

单独成段，全书约 **190 次**。这不是省略号，是一个**节拍**，表示"这人被噎住了/懒得理你/无话可说"。
用在吐槽之后、无理取闹之后、被戳穿之后。**这是这个文风辨识度最高的单一装置。**

### 对话的信息密度

- 闲聊时短、碎、互相拆台
- 讲正事时**一个人一口气讲完整段推理，别人不许插嘴** —— 长度可以是 200 字以上一整段
- 长短切换本身就是人物状态的信号

## 四、两台修辞机器

### 机器 1：具象比喻

```
[具体的动物/家什/日常物] + 似的/一般 + 动词
```

每万字约 **7 次**（约每 1400 字一个）。

喻体必须是**这个世界里真实存在、人物见过的东西**：毒蛇出洞、游鱼、羽毛落地、树瘤、碎金、布条、王八、狗洞。

**严禁抽象喻体。** "潮水般的悲伤"、"刀绞一般的痛"这类是 AI 库存，一个都不许出现。

自造示例（本 skill 原创，非引文）：

- ✗ 他的手抖得厉害。
- ✓ 他那只手抖得筛糠似的，怎么按也按不住。
- ✗ 她心里很乱。
- ✓ 她脑子里那点念头乱得像一锅炸开的蚂蚁，抓哪个哪个跑。

### 机器 2：夸张假设句

```
倘若把 X [倒过来 / 拧一拧 / 剖开 / 称一称]，约莫能 + [荒诞的量化结果]
```

用一个物理动作把抽象性格**量化**。这是 古典体刻画人物最狠的一招 —— 一句顶三段。

自造示例：

> 倘若把这位掌门肚子里的心眼倒出来筛一遍，能挑出三斗算计，一粒真心。

## 五、冷幽默的三种打法

1. **叙述者替人物说出他不会说的粗话** —— 人物只是走开了，叙述者说她"拿人当了个屁"。
2. **让天地万物有意见** —— 主角抛铜钱问卦，叙述者说老天爷决心治治他。
3. **给严肃场面一个不庄重的收尾细节** —— 生死攸关的卜卦，铜钱卡在石缝里侧躺着。

共同点：**幽默永远来自叙述者的态度，不来自人物讲笑话。**

## 六、情绪处理的铁律

**痛处只给一闪，然后立刻由人物自己用玩笑盖过去。**

标准三拍：

1. 一个无心的问题戳中旧伤
2. 人物**失控半秒**（叙述者可见：咬牙、线条变锋利、目光里几样东西接连闪过）
3. 人物立刻用更夸张的自吹/耍宝盖住 —— **这个"盖"的动作本身就是他的人格**

叙述者绝不解释他痛什么。读者从"他要盖"这件事本身推出来。

配套：**叙述者可以自己叹一口气，但只用省略号，不用完整句。**

```
……可惜这话如今再没有第二个人听得懂了。
```

## 七、角色声音卡

写多人对话时，**每个角色分配一张卡，卡与卡之间必须句长不同、句式不同**。

> 下列台词样本全部为自撰，用途是**定语气**，不是素材库。
> 不要把它们抄进正文 —— 照着这个音高重新生成属于你那个角色的句子。

---

### A · 硬派

- 句长 **≤ 12 字**
- **反问句是主武器**
- **从不解释动机**，被问就顶回去
- 内心独白是自嘲 + 务实盘算，用大白话和土比喻
- **生气时话最长**，且是排比式的挖苦 —— 这是唯一允许她说长句的场合
- 从不说"我担心你"，关心一律用行动或一句难听的话表达

**台词样本**

| 情境 | 台词 |
|---|---|
| 有人搭话 | 「有事说事。」 |
| 被称赞 | 「与你何干。」 |
| 有人替她做主 | 「我的刀，我自己拿。」 |
| 被顶撞 | 「我几时说过要你管？」 |
| 被追问来历 | 「问这么多做什么，你是要给我立碑么？」 |
| 讲正事（短分句串起来，仍不解释） | 「你带他从后山走，我在桥上等。天亮前他没过江，你也不必回来了。」 |
| 生气（唯一的长句，排比式挖苦） | 「好，你有理。你处处有理，你连我娘都算计得清清楚楚，我这条命想必也是你算出来的 —— 我该谢你八辈祖宗。」 |
| 关心人（用难听话说） | 「要死死远点，别脏了我的刀。」 |
| 被戳中痛处 | 「……」（转身就走，一个字不给） |

**她绝不会说**：「我担心你。」「我是为你好。」「你听我解释。」
这三句任何一句出现，这个角色就废了。

---

### B · 贫嘴

- **有问必答，但答的不是那个问题**
- 拽文、用典、给自己封名号（是玩笑不是威严）
- 讲正事时**句子突然变长变准**，一口气把推理讲完
- 被戳到痛处 → 走"情绪处理"三拍
- 关键：**他的贫嘴不是性格调剂，是防御工事**。写的时候要知道他在挡什么

**台词样本**

| 情境 | 台词 |
|---|---|
| 被问姓名 | 「在下姓温，单名一个言字。至于表字么，还空着，姑娘若肯赏一个，我这就去改族谱。」 |
| 被问正经事（答非所问） | 「你问这个做什么？这镇上的茶比黄连还苦，你先喝一口，喝完了咱们再论天下大事。」 |
| 自吹 | 「我平生只怕两样东西：一是不讲理的女人，二是讲理的女人。」 |
| 被拆穿 | 「哎哎哎，话不能这么说 —— 话可以这么说，但不能由你来说。」 |
| 讲正事（突然变长变准，一口气到底） | 「他昨夜不走大路，是因为大路上有人等；今早不走小路，是因为小路上等的人更多。两条路都不走，那就只剩水路。你这会儿动身去码头，还赶得上。」 |
| 罕见的认真（句子突然变短） | 「这一回，你听我的。」 |
| 被戳中痛处（失控半秒 → 立刻盖住） | 「……」他脸上那点笑僵了一瞬，随即笑得更没心没肺：「问得好！来，我教你个更妙的问法 ——」 |

**他绝不会说**：任何一句直接承认自己难受的话。
他的痛只能从"他急着盖住"这个动作里看出来 —— 盖的动作本身就是他的人格。

---

### C · 端着

- 短应答，不愿多说，把真话咽回去
- **心里话由叙述者代述**，人物本人一句不说

**台词样本**

| 情境 | 台词 |
|---|---|
| 应答 | 「嗯。」 |
| 拒绝 | 「不必了。」 |
| 划清界限 | 「我跟你不一样。」 |
| 被追问 | 「……没什么。」 |
| 再被追问 | 「我说了没什么。」 |
| 罕见的真话（说一半就停） | 「我只是……算了。」 |

**他绝不会把心里话说完整。** 那部分全部交给叙述者代述。

---

### D · 长辈 / 强者

- 出场靠别人怕他/她，本人可以很久不说话
- 说话不留情面，不解释，不安慰
- 用"倘若…拧一拧"机器一句写完性格

**台词样本**

| 情境 | 台词 |
|---|---|
| 罚人 | 「跪着想。什么时候想明白，什么时候起来。」 |
| 不解释 | 「我不问你愿不愿意。」 |
| 不留情面 | 「输了就是输了，哪来这么多话。」 |
| 一句戳心 | 「你爹当年也是这么说的。」 |
| 罕见的温和（比骂人更吓人） | 「……去吧。」 |

---

### 同题对照

同一个问题，四张卡各答一句。**语气差异应该一眼可见 —— 遮住名字也能认出是谁。**

情境：有人问「这事你为什么要管？」

| 卡 | 回答 |
|---|---|
| 硬派 | 「我乐意。」 |
| 贫嘴 | 「不管不行啊，我这人天生见不得热闹里没我一份。」 |
| 端着 | 「与你无关。」 |
| 长辈 | 「轮不到你问。」 |

写完多人对话后做这个测试：**把所有引号内容抽出来，遮住说话人。认不出谁是谁，就是没写好。**

## 八、结构

- **章标题：2–4 字名词**。挨打、诀别、亡命、布局、入彀、绝响。不用完整句，不剧透。
- **开场公式**：
  1. 时间地点一句（朝代 + 年号 + 季节）
  2. 景物两个四字短语
  3. 直接切进一个**正在进行的具体动作**

  不做背景铺垫，不介绍人物。人物是谁靠旁观者交头接耳带出来。

- **视角切换**：换场景就换视角，用一个空行 + 新场景的动作直接接上，不写"与此同时"。

## 九、自检

写完 grep 一遍：

```bash
grep -c "说：" 稿子.txt      # 必须为 0
grep -c "道：" 稿子.txt      # 每千字应有 4 次以上
grep -c "便"   稿子.txt      # 每万字应有 18 次以上(原著 34.8)
grep -c "似的" 稿子.txt      # 每万字应有 5 次以上
grep -nE "感到|内心深处|情绪|氛围|一抹|涌起" 稿子.txt   # 应为空
```

或直接跑 `python scripts/check.py 稿子.txt --style classical`。
